Notification is a compact, single-line in-page banner. Use it for lightweight status messages — often with an optional trailing link — where a full Alert card would be too heavy and a Toast too fleeting.

        <h2>When to use</h2>

        <ul>
          <li><strong>Inline status</strong> — a concise, persistent message tied to a page or section.</li>
          <li><strong>Contextual nudges</strong> — pair with a link to point users to the next step.</li>
        </ul>

        <h2>When not to use</h2>

        <ul>
          <li>When you need a title plus a longer body or action buttons → use an <code>Alert</code>.</li>
          <li>For transient confirmations that auto-dismiss → use a <code>Toast</code>.</li>
          <li>For decisions that require a response → use a <code>Modal</code>.</li>
        </ul>

        <h2>Intent</h2>

        <ul>
          <li><strong>success</strong> — an operation completed as expected.</li>
          <li><strong>info</strong> — neutral, non-urgent context.</li>
          <li><strong>warning</strong> — the user should review something before proceeding.</li>
          <li><strong>error</strong> — something failed and needs attention.</li>
        </ul>

        <h2>Writing</h2>

        <ul>
          <li>Aim for a single scannable line; let longer content wrap rather than truncating.</li>
          <li>Keep the link label to one or two words that name the destination or action.</li>
        </ul>
      </>
    ),
