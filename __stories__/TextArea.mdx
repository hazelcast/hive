TextArea is the control for multi-line, free-form text input. Use it for
descriptions, comments, notes and any value that needs more than a single line.
For short single-line input prefer `TextField`; for numeric input prefer
`NumberField`.

        <h2>When to use a TextArea</h2>

        <ul>

          <li>When the expected input is likely to exceed a single line.</li>
        </ul>

        <h3>When <em>not</em> to use a TextArea</h3>

        <ul>
          <li>For short single-line input — names, IDs, URLs → use a <code>TextField</code>.</li>
          <li>For a fixed list of options → use a <code>SelectField</code> or <code>RadioGroup</code>.</li>
        </ul>

        <h2>Labels and placeholders</h2>

        <p>Every TextArea needs a visible <code>label</code>. Use <code>placeholder</code> only for an example of the expected content — never as a replacement for the label, since it disappears on input.</p>
