NumberField is the control for numeric input. It builds on `TextField`, adding
increment / decrement steppers, `min` / `max` clamping, and integer or float
parsing. It renders at a single “Regular” size. Use it for counts, ports, sizes,
replicas, timeouts and any other value that is fundamentally a number. For
free-form text use `TextField`; for a fixed list of choices use `SelectField`.
